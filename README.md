# Soprana AI Solutions

Landing page da Soprana AI Solutions: consultoria e soluções em inteligência artificial, em linguagem simples.

## Estrutura

- `index.html`: a página (HTML e CSS)
- `script.js`: glossário interativo e formulário
- `logo.png`: logomarca

## Como ver no seu computador

Abra o `index.html` no navegador (duplo clique).

## Pendência conhecida

O formulário de contato ainda não envia os dados para lugar nenhum. Ele mostra um resumo para copiar. Conectar a um serviço de formulários ou a um e-mail é o próximo passo.
